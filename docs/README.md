# Project Documentation: Advanced Encryption Tool

## Overview
The Advanced Encryption Tool is designed for robust file encryption and decryption using AES-256 encryption with GCM mode. It includes a user-friendly interface to make the encryption and decryption process seamless.

## Features
- **AES-256 Encryption**: Ensures file confidentiality and integrity.
- **User-Friendly GUI**: Simple interface for file operations.
- **Secure Key Derivation**: Uses PBKDF2 with a password to generate a strong key.
